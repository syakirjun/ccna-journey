## What I learned

### RJ45 Connector

- Most of ports use Registered Jack.
- Used on the end of copper Ethernet cable.
- Vary in design, colours but still the same.

### Ethernet

- A protocol or standards for device to communicate each other.
- Ethernet = Cable.

### Network Protocol

- Define example as RJ45 connected to USB port. There is no standard. Nobody connected to nobody. Wrong hole.
- Other example can be define in TCP/IP protocol.

### Bits and Bytes

- 1 and 0 is a binary.
- 1 byte = 10101010 (8 bits).
- Speed is measured by bits per second (kbps, mbps, gbps)
- Storage is measured by bytes.

### Ethernet Standars (copper)

    SPEED       COMMON NAME      IEEE STANDARD  INFORMAL     MAXIMUM
                                                  NAME        LENGHT

- 10 Mbps   =     Etherner      =   802.3i   =   10BASE-T     = 100 M  
- 100 Mbps  =   Fast Ethernet   =   802.3u   =   100BASE-T    = 100 M
- 1 Gbps    = Gigabit Ethernet  =   802.3ab  =  1000BASE-T    = 100 M
- 10 Gbps   =  10 Gig Ethernet  =   802.3an  =   10GBASE-T    = 100 M

- BASE = Baseband
- T = Twisted Pair
